# A2 - IIoT Protocol Primer
## 1. Introduction
Industrial internet of things (IIOT) connects industrial machines , sensors , controllers and sofware systems . It helps factories collect and analyse production data.
## 2. Comparison Table 
| Protocol | model | transport | typical use |
|---|---|---|---|
| MQTT |Lightweight  messaging devices and applications | sending CNC machine temperature data to a cloud Dashboard |
| OPC UA | secure and  structured industrial data communication | connecting  a PLC with  a SCADA monitoring system |
|HTTP/REST| communication between applications and web services | sending production information to a cloud applications |

## 3.Pratical Industrial Example 
 Consider a CNC Machining Factory
1. sensors measure machine temperature and vibration
2. A PLC collects machine information .
3. OPC UA or Modbus can transfer industrial data.
4. An IOT gateway sends selected data using MQTT.
5. A cloud Dashboard displays machine performance.
6. Engineers analyse the information and identify possible machine problems.

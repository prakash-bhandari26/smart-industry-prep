# A1 – Cloud paradigm Notes ( IaaS, PaaS, SaaS)

## 1. Comparison Table

| Paradigm | You Manage | Provider Manages | Industrial Example |
|---|---|---|---|
| IaaS | Operating system, middleware, runtime, applications and data | Physical servers, storage, networking and virtualization | A CNC manufacturing company runs its machine monitoring software on AWS EC2 virtual machines. |
| PaaS | Applications and data | Operating system, runtime, middleware and infrastructure | A production engineer develops a machine monitoring dashboard using Azure App Service without managing servers. |
| SaaS | User accounts and basic configuration | Complete application and infrastructure | A factory uses cloud-based maintenance management software to track machine breakdowns and maintenance schedules. |

## 2. When Would a Factory Choose Each Model?

- IaaS: When a factory needs more control over its operating system and specialised industrial software.
- PaaS: When engineers want to develop their own applications and dashboards without managing servers.
- SaaS: When a factory needs ready-made software with minimal IT maintenance.

## 3. Industrial Applications

- IaaS: A CNC factory stores machine monitoring software on cloud virtual machines.
- PaaS: A production engineer develops a dashboard to monitor machine performance and production data.
- SaaS: A manufacturing company uses cloud-based software to manage maintenance schedules and quality records.

## 4. Key Takeaways

- IaaS provides the highest infrastructure control.
- PaaS makes application development easier.
- SaaS provides ready-to-use software.
- Factories can combine all three models depending on their needs.

## 5. Conclusion

Cloud computing helps manufacturing companies improve efficiency, monitor production and manage industrial data. The choice of cloud model depends on the company's technical requirements, budget and IT skills.
